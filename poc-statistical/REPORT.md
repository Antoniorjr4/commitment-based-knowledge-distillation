# Certified Distillation Proof-of-Concept — Experimental Report

## Scope
This prototype implements a reduced, executable test of the paper's protocol mechanics:
cryptographic commitments, Merkle inclusion proofs, post-commitment-style deterministic sampling,
deterministic INT8/INT32 inference, a bounded zero-one disagreement metric, a Hoeffding upper
confidence bound, certificate generation, independent verification, and tamper detection.

It does **not** implement a TEE attestation, zkSNARK/recursive folding, an EVM dispute contract,
or a 70B→8B LLM experiment. Therefore it does not validate production-scale O(1) proof size,
sub-second zk verification, or the paper's target gas/edge-latency claims.

## Configuration
- Committed corpus N: 4096
- Audited subset n: 1024
- Input dimension: 16
- Output classes: 4
- Arithmetic: INT8 inputs/weights with INT32 accumulation
- Metric: zero-one teacher/student top-1 disagreement, bounded in [0,1]
- Confidence parameter delta: 0.05

## Results
- Empirical sampled disagreement d_hat: 0.054688 (56/1024)
- One-sided Hoeffding radius: 0.038246
- Certified statistical upper bound on mean disagreement: 0.092934
- Full committed-corpus disagreement (available only because this is a controlled PoC): 0.051514
- Certificate size: 3749.1 KiB
- Independent verification benchmark, mean over 20 runs: 37.039 ms
- Median verification: 36.978 ms
- Tamper test: PASS — changing one committed teacher output invalidates the certificate.

## Interpretation
The experiment validates the *mechanics* of binding an evaluation corpus and teacher-output table
to cryptographic roots, deriving a reproducible audit subset from public entropy, checking
inclusion openings, computing a bounded empirical loss, and attaching a mathematically valid
Hoeffding bound. It also demonstrates that post-commitment mutation is detectable.

The experiment does **not** prove that the committed teacher outputs were honestly generated by
the declared teacher model. A Merkle root proves integrity/binding after commitment, not execution
authenticity. The paper's Tier A/B/C mechanisms are needed for that additional claim.

Likewise, the statistical statement is about the assumed sampling distribution/committed corpus.
A random beacon prevents cherry-picking *after* commitment; it cannot make a biased corpus
representative of production traffic.

## Reproducibility
Run `python verify.py certificate.json` from this directory. It should print `VALID`.
Run `python verify.py certificate_tampered.json`; it should print `INVALID`.
